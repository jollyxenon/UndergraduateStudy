# 物理实验报告 Skill 使用说明

Skill 名称：`physics-lab-report`。

源文件保存在本目录 `skills/physics-lab-report/`，全局入口 `~/.pi/agent/skills/physics-lab-report` 指向该目录，只有一份需要维护的内容。重新加载 Pi 资源（`/reload`）后，可这样调用：

```text
/skill:physics-lab-report
根据我提供的实验数据生成本次物理实验报告。
实验名称：……
实验数据：……（图片、表格或文件路径）
本次特殊要求/教师批注：……
```

也可以直接说“用 physics-lab-report 处理这次实验数据”。Skill 会查找同实验的介绍、记录表与历史报告；已有材料中的信息不重复询问，只有关键读数、仪器参数等确实缺失时才集中询问。

## 已固定的偏好

- 用户实测数据是唯一的实验数据来源。
- 中文 LaTeX，尽量沿用历史报告的标题、数据组织与课程风格；图表黑白优先，确需彩色先选红蓝。
- 直接量、间接量、拟合参数和最终结果的不确定度完整，不能只写定性误差分析。
- 正文末尾依次为实验结论、误差分析、思考题；题目从当次介绍全文提取，遵循选做要求。
- 默认实验后数据处理报告，不附加长篇预习内容；用户要求完整报告时再补。
- 正文模仿历史报告中自然、直接的学生语言：写测量数据、计算过程、不确定度和结论。直接使用课程约定，不写“根据操作手册”“实验介绍中给出”等来源交代，不堆砌定义、标准说明、适用范围声明、自我辩护或未做事项。必要来源和核验细节放在独立的计算说明；思考题问到的定义正常回答。

## 当前验证记录

- 已读取八类历史报告全文、十份当前实验介绍和当前课程绪论；对关键历史页面作图像核对。
- 配套九份 XLSX 已枚举工作表和抽查公式结构，没有宣称完成所有历史单元格的逐格审计。
- 核对了 Skill 元数据限制及文件引用；核心规则覆盖了用户四项要求。
- 独立复算了历史转动惯量的数量级问题、个人密度报告的粗差阈值，以及个人杨氏模量的加力拟合与直径统计量。
- 已在 WSL 通过 pixi 提供的 Tectonic 编译 LaTeX 模板；无溢出、缺字、未定义命令或 LaTeX 警告，已查看全部两页。模板为骨架，正式内容填入后必须重新编译和逐页检查。
- 没有修改原有两份实验报告；没有用本 Skill 重新生成一份完整的新实验报告。下一次实际报告仍需按本次数据完成全过程核验。

本环境可用的模板编译命令（在本目录执行，先创建 `build` 输出目录）：

```bash
pixi exec --spec tectonic -- tectonic --keep-logs --outdir build skills/physics-lab-report/assets/report-template.tex
```

普通 XeLaTeX 环境也可编译该模板，采用 TeX 自带 Fandol 中文字体，不依赖 Windows 字体配置。运行 shell 时遵循环境的 rtk 规范，为上述命令加 `rtk proxy` 前缀。

## 后续维护

新教师批注或新的历史材料应补充到对应参考文件，并回查是否影响主流程。只修改源目录，不另维护一份全局副本。若移动本目录，需更新全局符号链接；完整 Skill 目录也可复制到其他工具的 skills 目录使用。
