# 物理实验报告工作区

开始报告生成、修订或教师批注处理前，读取 `报告生成说明.md` 和 `skills/physics-lab-report/SKILL.md`，再按需读取其参考文件。

本工作区使用用户自己的实测数据。历史资料位于上一级 `Historical Material/`，可能被 Git 忽略，搜索使用 `fd -H -I`；`Experiment Report/` 是空白记录表，`Experiment Introduction/` 是当前实验要求与思考题来源。

报告使用中文 LaTeX，黑白优先，必要彩色优先红蓝；中间量与最终量均完整评定不确定度；最后三个正文板块依次为实验结论、误差分析、思考题。按当前课程已核实的简化不确定度口径处理，不与标准不确定度口径混用。

Skill 的唯一源目录为本工作区 `skills/physics-lab-report/`，全局技能入口指向这里。具体蒸馏证据、计算要求和核验记录以 Skill 及 `报告生成说明.md` 为准。处理新报告时不顺手改其他已完成报告。
