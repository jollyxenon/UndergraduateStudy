# 交付前检查

每次报告完成后在 `计算说明.md` 简短记录实际完成的检查和未解决项，不只勾选模板。以下是人工与运行核验清单，不要求编写测试套件。

## 数据与来源

- [ ] 全部实验数值来自用户本次记录，图像数字已经对照原件；没有用历史数据填空。
- [ ] 原始数据、零差修正和处理后数据可区分；没有提前修约改变判别结果。
- [ ] 仪器分度、允许误差、环境温度、参考物理量有来源；未沿用历史作者身份和实验经历。
- [ ] 实际实验任务与选做任务明确；需补做但缺数据的部分已说明，不虚构。

## 物理与计算

- [ ] 原理模型、符号、横纵轴和单位一致，斜率与反斜率、半径与直径、脉冲与周期均核实。
- [ ] 从原始数据重新运行计算；公式、示范代入、表格、图和结论使用同一结果。
- [ ] 每个关键结果独立检查数量级与量纲，至少一组代表计算用不同表达方式复算；相对偏差合理不代替绝对值核验。
- [ ] 标准差、均值标准差、n、自由度、t分位数正确；未把粗差判别范围叫均值置信区间。
- [ ] 删除/保留可疑点有明确规则和未修约证据，不能为了贴近理论答案改数据。
- [ ] 模型适用条件已有数据或操作依据；适用范围以外不强行套公式。

## 不确定度

- [ ] 计算记录明确所用口径，所有分量的含义及覆盖水平统一；正文直接给公式和所取P或κ，不增加标准辨析。
- [ ] 一次性测量、零点、参考量、拟合参数等全部纳入或有可量化的忽略依据；缺失不确定度没有填零。
- [ ] 中间测量结果和最终物理量都有适用的不确定度；并非只在直径、时间处写±。
- [ ] 共用零点、参考物、校准参数及差值的相关性已经评估，无双重计入。
- [ ] 拟合给参数不确定度和残差评价，不只给R²；平均斜率传播正确。
- [ ] 最终结果单位、修约、相对不确定度及P/κ说明完整。给定参数的处理依据留在计算说明；确有影响结果理解的特殊条件，仅在相关位置说明一次。
- [ ] 参考偏差与不确定度分开；方法或定理比较考虑差值的不确定度。

## 叙述与结构

- [ ] 语言模仿历史报告中的自然学生表达，直接写数据、计算、不确定度和结论；没有“根据操作手册”“实验介绍中给出”等来源交代。
- [ ] 没有多余的概念定义、标准选择声明、重复限定、自我辩护和未做事项；思考题要求的定义照常回答。
- [ ] 公式、必要代入、剔除依据和计算结果完整；详细来源、相关性和完整预算留在计算记录，未为满足内部核验而堆砌正文。

- [ ] 最后三个正文板块依次是实验结论、误差分析、思考题。
- [ ] 结论回答实验目的，列所有最终结果；没有“没有数据支持的验证成功”。
- [ ] 误差主次依据预算；方向由物理模型判断；推测与实际观察明确区分。
- [ ] 思考题来自当次介绍全文，含正文中嵌入的题目；遵循选做规则，保留原题，理论与实测分开。
- [ ] 已知讲义没有思考题时如实说明，不补造题；历史报告缺结论或思考题不作为省略依据。

## 排版与交付

- [ ] `.tex` 可编辑，图表不使用历史截图；黑白优先，必要彩色优先红蓝且有线型/点型辅助。
- [ ] 表头与坐标轴单位齐全，图例、误差棒含义明确；字号和线宽适于打印。
- [ ] 所有LaTeX引用资源随报告保留，未保留示例数据或“待填写”作为正式内容。
- [ ] 完成编译，检查错误、缺字、引用和溢出；编译不了则明确交付状态。
- [ ] PDF逐页查看，检查裁切、分页、表格宽度、公式和页底；不能只看第一页。
- [ ] 交付源文件、PDF（若已生成）、可复算数据与脚本、简短计算说明；临时文件放build，不污染正文目录。
